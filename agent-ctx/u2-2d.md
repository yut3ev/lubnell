## Known limitations

1. **No `updatedAt` on live `Product`/`Category`** — schema only has `createdAt` (can't touch prisma). lastmod = `createdAt`; og cache signature uses `createdAt+price` / `createdAt+count+name`. Price/count/name edits still invalidate; description/image-only edits won't (image edits usually come with price/name churn via admin, low risk).
2. **OG type `product`** not emit-able via Next `Metadata` union — `website` used (Google reads Product via JSON-LD anyway).
3. **Unpublished-product metadata**: generateMetadata returns meta before the published check in the page body; the page itself 404s, so no indexable content — cosmetic only.
4. Canonical/OG URLs are absolute from request headers → in sandbox they read `http://localhost:3000/…`; in prod behind the real host they resolve to the true origin (established codebase pattern), while layout `metadataBase` stays `https://lubnel.com` for relative-URL resolution.
5. `aggregateRating` fallback: products with zero approved reviews still expose seeded rating/reviews (pre-existing behavior, kept deliberately).
