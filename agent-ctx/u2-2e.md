## Bulk API contract — `PATCH|POST /api/admin/products/bulk`
- Auth: `requireAdmin` + `products.write` → `401 {ok:false}` otherwise (verified).
- Body `{ ids: string[], action: 'publish'|'unpublish'|'feature'|'unfeature'|'delete' }`;
  ids deduped/trimmed, must be non-empty, **≤200**; unknown action → `400` with Arabic error.
- Non-delete actions → `db.product.updateMany` → `{ ok:true, affected }`.
- `delete` mirrors single-DELETE soft semantics exactly: order-item-referenced products are **cleared in a
  `$transaction`** (`stock:0, featured:false, badgeAr/badgeEn:null`) and never hard-deleted; unreferenced are
  `deleteMany`'d → `{ ok:true, affected, cleared, deleted }`.
- Audit: one `writeAudit` per action — `action: 'products.bulk.<action>:<affected>'` (count+action+actor in one
  row; still matches audit filter `contains: products.bulk`), `entity:'product'`, `entityId:null`, ip in meta.
- Response `{ ok, affected }` (+ `cleared`/`deleted` for delete).
