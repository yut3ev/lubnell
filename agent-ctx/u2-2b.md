## API contract — GET /api/products

| Param | Meaning |
|---|---|
| `q` | contains-match on nameAr / nameEn / description |
| `category` | category slug |
| `sort` | `newest` \| `oldest` \| `price-asc` \| `price-desc` \| `best-selling` (+ internal extras `featured`, `rating`); default = legacy `oldest` (createdAt asc) |
| `minPrice` / `maxPrice` | inclusive price bounds (EGP) |
| `inStock` | `1`/`true` → only `stock > 0` |
| `page` | 1-based; presence of `page`/`pageSize` enables pagination |
| `pageSize` | default 12, capped at 48 |

Response: `{ ok: true, products: ProductCardDto[], total, page, pageSize }`
(without paging params → all matches, legacy-compatible).

Examples:
```
/api/products?sort=price-asc&pageSize=3
/api/products?q=lip&inStock=1
/api/products?sort=best-selling&page=2&pageSize=4
/api/products?category=makeup&maxPrice=120&sort=newest
```

## Known limitations

- **best-selling client-side approximation**: the client toolbar has no per-product sales data; `الأكثر مبيعًا` in `applyProductFilters` sorts by `reviews` desc. The API's `sort=best-selling` uses real OrderItem qty sums.
- **No Review aggregation in API**: cards use the denormalized `rating`/`reviews` columns on Product (cheap); per-request Review-table averaging skipped as optional.
- **«جديد» boundary**: computed from `Date.now()` at render; a product created ~14.0 days ago may flip between SSR/hydration views (cosmetic only).
- **gallery → images**: `Product.gallery` is a JSON string column; only `/api/products` and `/search` map it to `images[]`. Home/category constructors don't pass it, so Quick View thumbs show the single main image there.
- **Pagination UI**: API paginates, but storefront pages fetch-all client-side (per current architecture); page params are ready for future infinite scroll.
- **Leftover file**: `src/components/store/catalog-toolbar.tsx` (from the interrupted earlier pass) is now unused by any page but still compiles; left untouched to avoid racing the parallel agents.
- **search-dialog.tsx** is dead code after the header rewrite (kept on disk, out of scope to delete).
- Dev server was SIGTERM/restarted externally several times during QA by the environment/parallel agents; all green results above are from the final healthy instance.
